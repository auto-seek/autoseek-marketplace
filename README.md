# AutoSeek 原创市场

这个目录是一个可以独立发布的 Git 市场。根索引是 `.agents/plugins/marketplace.json`，每个子目录是一份可安装的包；一份包可以同时提供 team 模板、场景应用和插件能力。

| 包                               | 内容                                                                                  |
| -------------------------------- | ------------------------------------------------------------------------------------- |
| 夜班观测站 (`night-observatory`) | Mira 和 Sol 的工作团队、原始 Spec V2 角色卡、透明立绘、命名表情、提示音和团队场景应用 |
| 场景写作 (`scene-writing`)       | 用现有团队成员编写互动场景的技能                                                      |

同一个 team 成员既工作，也参与私聊和部门群聊，沿用自己的模型、权限、队列和上下文。点击部门名称进入群聊，点击图标展开/收起。只有被 @ 的成员响应；本次补送最近最多 100 条且合计 20,000 字符的群记录。

## 使用

AutoSeek 的插件市场内置此目录的快照。安装“夜班观测站”后，选择“fork 模板”生成自己的可编辑副本，再用该模板创建团队。进入团队的部门群，打开场景应用，点击角色或选择 @ 后发送消息。立绘、表情、背景、站位和手动音频播放使用这组真实成员；音频示例是提示音，不是人物配音。互动按钮只填入草稿，不会自动发消息。

发布此目录为独立 Git 仓库后，用户可在插件市场中添加仓库地址，勾选“把此仓库订阅为市场”。订阅和刷新只更新目录，安装使用经确认的具体版本。fork 的个人模板独立保存，市场更新、停用或卸载不会覆盖它。

## 贡献一份包

1. 从团队模板页导出团队包，将整个目录放在市场根目录下。导出会保存原卡、人物快照、本地素材、来源和资源哈希；不要提交私人对话或凭据。
2. 编辑包内 `.codex-plugin/plugin.json` 的名字、说明和版本。团队包用 `autoseek.templates` 声明；独立应用用 `autoseek.apps` 声明，路径均相对于包根。
3. 在根索引的 `plugins` 数组登记包名和本地相对路径。已有示例就是完整格式。
4. 更新已发布内容时提高包版本；相同版本不能替换为另一份内容。新应用仍需声明宿主能力，并经过原有信任流程。
5. 添加说明、预览和素材来源，再提交贡献。只提交自己有权分发的角色、图片和音频；每份贡献保留其许可说明。

例如，将场景放在 `scene/` 后，混合包清单可包含：

```json
{
  "name": "my-team",
  "version": "1.0.0",
  "description": "My team and its scene",
  "autoseek": { "templates": ["./"], "apps": ["./scene"] }
}
```

模板包中的 `team-package.json` 和 `assets/` 应一起提交。角色卡中的世界书、脚本、主题或其他扩展字段会保留；保留字段不表示 AutoSeek 已执行对应扩展。
