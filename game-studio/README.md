# 游戏工作室

制作人协调策划、工程、美术、音频和 QA。新游戏按角色分工；独立 QA 提供通过证据后，制作人才交付。
用户提供草图或参考图时，美术在预算内据图生成素材；生成不可用或超预算时才使用程序绘制并说明原因。

## 更新到 1.0.2

在插件页检查更新并更新游戏工作室，然后从新版包复制模板，用它创建团队。
已有个人模板独立保存，更新插件不会覆盖这些副本或现有团队。

本版同步角色分工、独立 QA、参考图生成、场景复刻与游戏试玩规则，包含六位成员及配套 `game-development` 技能。
制作人默认使用 `max`，其余成员默认使用 `pro`；可在团队配置中调整。

## 维护

规则来源是 Runtime 的 `templates/game-studio.yaml` 和 `skills/game-development/SKILL.md`。
更新时同步本包的 `team.yaml` 和技能文件，同时提高 `.codex-plugin/plugin.json` 中的包版本。
GUI 随包目录与公开市场应发布相同内容；市场仅用更高版本替换随包版本。
